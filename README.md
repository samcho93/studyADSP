## 로컬에서 보기

```bash
node tools/serve.js 8080
```

Windows 는 `start.bat`, 같은 네트워크의 학생에게는 `start-lan.bat`.

## 배포 (Cloudflare Pages)

```bash
npx wrangler pages deploy . --project-name studyadsp --branch main
```
